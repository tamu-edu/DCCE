### 4. CCID Overflow
Like other encoding schemes such as PCCE and DrCCTProf, DCCE has a limitation in terms of CCID overflow. However, we do not thin that DCCE would incur CCID overflow with a benchmark that PCCE does not. Distinguishable PCCE needs an extra storage for PC but DCCE does not. If DCCE uses the same bits that the distinguishable PCCE uses (bits for the encoding plus bits for PC), the total number of calling-context each encoding can cover are the same.
